# taskfile-agents v0.1.0

First public release of reusable Go-task adapters for five AI coding agents.

## Included agents
- **Claude Code:** `task agents:claude PROMPT="..."`
- **OpenAI Codex:** `task agents:codex PROMPT="..."`
- **GitHub Copilot CLI:** `task agents:copilot PROMPT="..."`
- **OpenCode:** `task agents:opencode PROMPT="..."`
- **Pi:** `task agents:pi PROMPT="..."`

## Highlights
- One shared interface: `PROMPT`, `PROMPT_FILE`, optional `MODEL`.
- Generic `task agents:run AGENT=... PROMPT="..."` selector.
- Git-hosted remote Taskfile includes for reuse across repositories.
- Safe-by-default CLI wrappers: no blanket permission bypass, optional Copilot tool allowlist, and Codex read-only sandbox by default.
- Self-contained Taskfile, examples, unit tests with stubbed CLIs, and GitHub Actions validation.

## Include in another Taskfile
```yaml
version: '3'
includes:
  agents: https://github.com/tbrandenburg/taskfile-agents.git//Taskfile.yml?ref=v0.1.0
```

Requires Go-task with remote include support and each chosen CLI installed/authenticated separately. Agent tools still follow their own local permissions and configuration.

## Notes
The CI tests mock the agent executables; this release does not claim end-to-end validation against paid model APIs.
