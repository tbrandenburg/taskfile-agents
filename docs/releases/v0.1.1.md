# taskfile-agents v0.1.1

Patch release adding optional output-format selection and reusable trusted instructions while preserving existing default CLI arguments and permission behavior.

## Highlights

- `FORMAT=text|jsonl`: default text output or native provider JSONL events for Claude, Codex, Copilot, OpenCode, and Pi. Event schemas remain provider-specific.
- `INSTRUCTIONS_FILE`: prepend a readable, nonempty local instructions file plus a blank line to the required `PROMPT` or `PROMPT_FILE`. Relative paths resolve from the caller's working directory.
- Existing optional `MODEL` selection remains a raw, quoted CLI-specific selector with no forced default.
- Expanded regression coverage for literal argument transport, invalid inputs, environment-carrier removal, and caller-relative local includes.

## Include in another Taskfile

```yaml
version: '3'
includes:
  agents: https://github.com/tbrandenburg/taskfile-agents.git//Taskfile.yml?ref=v0.1.1
```

```bash
task agents:codex PROMPT='Review the diff' FORMAT=jsonl INSTRUCTIONS_FILE=guides/review.md
```

## Validation and limitations

- The implementation PR's CI passed 17 tests with no skips.
- Real Codex, Copilot, OpenCode V2, and Pi passed text and JSONL checks: eight successful live invocations with explicit model selection and instruction-defined assistant responses.
- Claude live E2E is excluded because the test environment has no Claude subscription; its argument and instruction contracts are covered by executable-shim tests. No live-Claude success is claimed.
- Instructions are trusted user-prompt text, not a system-prompt override, native skill, or security boundary. Combined instructions and prompt remain visible in process arguments; do not include secrets.
- Each CLI must be installed and authenticated separately. No blanket tool approvals or permission bypasses were added.
